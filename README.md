# AI Business Intelligence Assistant 

An AI-powered application that allows users to ask questions about sales data in natural language and receive answers based on data analysis.

##  Features
- Ask sales-related questions in simple English.
- Analyze total revenue and product performance.
- View monthly revenue trends and regional sales.
- Process sales data from a CSV file.
- Generate data-driven answers through a backend API.

##  Tech Stack
- Python
- FastAPI
- Pandas
- Database and AI integration (as implemented)

##  Installation & Setup

**1. Clone the repository**
```bash
git clone <YOUR_GITHUB_REPOSITORY_URL>
cd <YOUR_PROJECT_FOLDER>
```

**2. Install dependencies**
```bash
pip install -r requirements.txt
```

**3. Run the application**
```bash
uvicorn main:app --reload
```

**4. Open API documentation**

Visit `[http://127.0.0.1:8000]`

##  Example Questions
- What is the total revenue?
- Which product generated the highest revenue?
- Which region generated the highest sales?
- What is the monthly revenue trend?
